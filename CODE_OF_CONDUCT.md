# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful, welcome newcomers, give and accept constructive feedback gracefully, and focus on what is best for the community. Harassment, insulting or derogatory comments, and personal or political attacks are not tolerated.

## Enforcement

Report unacceptable behavior by opening a private report through the repository's [Security Advisories](https://github.com/majiayu000/ephemera/security/advisories/new) page, or by contacting the maintainer [@majiayu000](https://github.com/majiayu000). All reports will be reviewed promptly and handled confidentially.

The full text, including enforcement guidelines, is available at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
