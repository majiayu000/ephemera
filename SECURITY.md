# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through [GitHub Security Advisories](https://github.com/majiayu000/ephemera/security/advisories/new). Include the affected file, steps to reproduce, and the browser you used. You should receive a response within 7 days.

## Scope

Ephemera is a set of static pages with no server component and no network requests at runtime. Relevant reports include script injection through URL parameters or other input, and anything that lets a page act outside the browser sandbox.
